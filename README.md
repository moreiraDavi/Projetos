# Projetos em Python 🐍

![Python](https://img.shields.io/badge/Python-3776AB?logo=python&logoColor=white&style=for-the-badge)

Meus primeiros exercícios de **Programação Orientada a Objetos** em Python, feitos no início da faculdade de Ciência da Computação.

---

## 📂 Arquivos

### [`DaviMoreiraPython2.py`](DaviMoreiraPython2.py) — classe `Pessoa`

- Atributos de nome, peso, altura e ano de nascimento, com *getters* e *setters* e validação de tipo
- `calcular_imc()`: calcula o Índice de Massa Corporal
- `calcular_idade()`: calcula a idade a partir do ano atual (`datetime`)

### [`DaviMoreiraPython3.py`](DaviMoreiraPython3.py) — classe `Point`

- Representa um ponto no plano cartesiano (x, y)
- `distancia()`: distância do ponto até a origem
- `distancia_dois_pontos()`: distância entre dois pontos
- `mostra_mais_distante()`: compara qual de dois pontos está mais longe da origem

## 🧠 Conceitos praticados

Classes e objetos · encapsulamento · métodos especiais (`__init__`, `__str__`) · módulos `math` e `datetime`

## 🚀 Como rodar

```bash
python DaviMoreiraPython2.py
python DaviMoreiraPython3.py
```
